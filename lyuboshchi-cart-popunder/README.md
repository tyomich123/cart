# Lyuboshchi Woo Cart Popunder

Плагін для WooCommerce, який після додавання товару в кошик показує popunder-модалку з:
- списком товарів у кошику,
- сумою кошика,
- кнопкою **Продовжити покупки**,
- кнопкою **Оформити замовлення**,
- посиланням на сторінку кошика,
- зміною кількості товару прямо у popunder,
- видаленням товару прямо у popunder.

## Встановлення
1. Скопіюйте папку `lyuboshchi-cart-popunder` в `wp-content/plugins/`.
2. Активуйте плагін у WordPress (`Плагіни` → `Lyuboshchi Woo Cart Popunder`).
3. Переконайтеся, що WooCommerce активний.

## Сумісність
- AJAX-додавання товару (подія `added_to_cart`).
- Додавання без AJAX (через перезавантаження сторінки).
- Адаптивний інтерфейс для desktop/tablet/mobile.

## Стилізація
Дизайн виконаний у темній неоновій стилістиці з фіолетово-рожевим градієнтом, близькій до референсів.
